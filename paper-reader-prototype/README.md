# 杭电计算机学院论文初筛阅读助手

公开演示：[论文初筛阅读助手](https://mio956.github.io/AIGC/paper-reader-prototype/)


基于 Vite、原生 JavaScript 与 PDF.js 的纯前端原型。PDF 在浏览器中解析，不会上传到存储服务。首次打开默认提供清楚标注为演示数据的样例卡片；上传 PDF 后，本地提取可复制文本，再用可解释的本地关键词规则生成**演示分析**，不等同于模型结论。

## 启动

```bash
npm install
npm run dev
```

在终端打开 Vite 输出的本地网址。也可以执行 `npm run build` 构建静态页面，再执行 `npm run preview` 预览构建结果。

## 使用说明

- 点击或拖拽上传单篇 PDF；处理上限为 50 MB、300 页和 250,000 个字符。页码随提取文本保留。扫描件会提示当前版本不支持 OCR。
- 搜索标题和关键词、按正式研究所名称过滤，点击卡片查看结构化摘要和分类依据。
- 问答通过当前所选论文的逐页原文进行本地检索。没有找到相关依据时回答“论文中未找到相关信息”。切换论文后问答区域重置。
- 所有方向建议均仅供初筛参考，请人工核对。演示规则对关键词进行匹配，关键词重叠时不构成准确分类。

## 文件与模块

- `src/pdf.js`：PDF.js 本地文字解析、页码保留和文件大小/页数/文本保护。
- `src/paperAnalysis.js`：分析适配层、固定 JSON 论文卡片结构、本地演示分析和研究所标签。
- `src/main.js`：交互状态、卡片/详情渲染、过滤、上传和基于原文的问答。
- `src/style.css`：响应式科研阅读界面。

## 模型接口预留

`analyzeWithModel(text, config)` 是独立适配边界。接入真实模型前，需要选定模型服务和 JSON Schema/结构化输出约定，以及一个同源后端代理地址（如 `endpoint`）；后端负责保存 API Key 并调用模型。不要将真实 Key 放进浏览器源码、`VITE_*` 环境变量、静态网页或公开 Git 仓库中，因为浏览器端配置对用户可见。第一阶段此接口通过 `null` 配置运行本地演示分析，未配置时不会发出网络请求。
